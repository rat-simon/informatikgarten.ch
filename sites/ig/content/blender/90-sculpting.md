## Wichtige Erkenntnisse

**Sculpting Workflow Essentials:**
1. **Hardware Setup**: Tablet stark empfohlen, richtige Button-Konfiguration
2. **Progressive Detail**: Niedrige Details lange beibehalten für bessere Kontrolle
3. **Remesh Strategy**: Voxel Size anpassen basierend auf Hardware und Detail-Bedarf
4. **Symmetry**: X-Axis Symmetry für effiziente Character Creation

**Essential Shortcuts:**
- **F**: Brush Size
- **Shift**: Quick Smooth Brush
- **Ctrl**: Brush Reverse (Push inwards)
- **Ctrl + R**: Remesh
- **R**: Voxel Size Preview
- **Alt + Q**: Object Selection in Sculpt Mode

**Professional Techniques:**
- Icosphere mit Subdivision 5 als optimaler Start
- Progressive Detail-Erhöhung nur bei Bedarf
- Draw Brush für Additions, Control für Subtractions
- Mirror Modifier für symmetrische Features
- Layout Workspace für Object-Management

**Performance Management:**
- Statistics Overlay für Face Count Monitoring
- Hardware-angepasste Voxel Sizes
- Remesh bei Polygon-Stretching
- Smooth Brush für Surface Refinement

**Character Development Pipeline:**
1. Basic Head Shape (Grab Brush)
2. Major Features (Nose, Eye Sockets, Ears)
3. Detail Addition (Eyes, Lips, Nostrils)
4. Fine Details (Eyelids, Brows, Ear Details)
5. Final Polish (Overall Shape, Expression)

Dieses Tutorial bietet eine komplette Foundation für Character Sculpting in Blender - von den ersten Schritten bis zum fertigen, ausdrucksstarken Gesicht!
